# Портфолио IT-администратора

Статичный сайт в ASCII/терминальном стиле под алой луной: открывается двойным кликом по `index.html`,
сервер и сборка не нужны.

## Страницы

| Адрес | Страница |
|---|---|
| `#home` | **Главная** — только логотип: по нему постоянно проходят глитч-сбои (сдвиг строк, «битые» символы, расслоение цвета); наведение или клик — сильный сбой. За логотипом — огромная алая луна. |
| `#services` | **01. Услуги** — у каждой услуги большая анимированная картинка (блоки по очереди слева и справа). |
| `#about` | **02. О себе** — кто я, навыки (плитки с анимированными значками; клик открывает подробности), опыт и сертификаты. |
| `#info` | **03. Инфо** — анимированная карта мира с точкой посетителя, его IP, место и координаты; ниже терминал. |
| `#contact` | **04. Контакты** — карточки с анимированными картинками (github, telegram, телефон, почта). |

Старые адреса (`#office`, `#skills`, `#terminal` и др.) открывают соответствующие новые страницы.
Работают кнопки браузера «Назад/Вперёд»; на каждой странице есть ссылка `← меню`.

## Услуги (`services` в `js/data.js`)

| № | Услуга | Анимация |
|---|---|---|
| 01 | Установка и настройка серверов | стойка с индикаторами, загрузка виртуальных машин и контейнеров |
| 02 | Монтаж СКС и видеонаблюдения | 3D-схема офиса: кабели с пакетами, роутер, NVR, коммутатор, сервер, 4 камеры с конусами обзора, изображение с камер, рисунки камер |
| 03 | Настройка сетей и Wi-Fi | пакеты бегут по сети, ping |
| 04 | Windows Server и Active Directory | создание пользователя в AD, групповая политика |
| 05 | Linux-серверы и автоматизация | htop с живой нагрузкой |
| 06 | Мониторинг и резервное копирование | живой график, тревога, ночной бэкап |
| 07 | Обслуживание компьютеров и оргтехники | системный блок и чек-лист обслуживания, температура падает |
| 08 | Создание сайтов | страница собирается из блоков-тегов |

Новая услуга — новый объект в массиве `services`: `title`, `desc`, `points` (строки или `{ ru, uz, en }`)
и `scene` — имя анимации из `js/scenes.js` (`servers`, `network`, `windows`, `linux`, `monitoring`, `pc`, `html`,
`cctv` и др.). `feature: "office"` вместо картинки показывает 3D-схему офиса.

## Инфо: IP, место и координаты посетителя

- **Внешний IP**, город, провайдер и координаты — из публичного сервиса ipwho.is (запасной — ipapi.co).
  Запрос уходит из браузера посетителя, только когда он открыл страницу «Инфо».
- **Локальный IP** проверяется через WebRTC без внешних запросов. Современные браузеры его скрывают
  (показывают маску вида `xxxx.local`) — тогда так и написано: «скрыт браузером».
- Если сервис недоступен (например, внутри песочницы claude.ai внешние запросы запрещены), место и
  координаты показываются примерно по часовому поясу, без IP.
- Также показываются часовой пояс, время, браузер, система, экран и язык — всё видит только сам посетитель.
- На карте: полоса радара, перекрестие через точку посетителя, «пинг»-кольца, табличка с координатами
  и сигнал от вашего города (`profile.location` в `js/data.js`).

## Структура файлов

```
portfolio/
├── index.html         — каркас: шапка, страницы, подвал
├── img/logo.png       — логотип (шапка, «О себе», исходник для ASCII)
├── css/style.css      — стиль, темы, адаптивность, анимации
└── js/
    ├── i18n.js        — переводы интерфейса: ru, uz, en
    ├── data.js        — ВСЁ содержимое: профиль, услуги, навыки, опыт, сертификаты, контакты
    ├── ascii-logo.js  — логотип как сетка яркости (сгенерирована из logo.png)
    ├── fx.js          — ASCII-эффекты: расшифровка текста, логотип и его глитч
    ├── sound.js       — звуки интерфейса (Web Audio, без файлов)
    ├── background.js  — фон: алая луна, звёзды, облака, линии уровня, режим матрицы
    ├── scenes.js      — большие ASCII-анимации (услуги и навыки)
    ├── icons.js       — анимированные значки навыков и картинки контактов
    ├── main.js        — страницы и переходы, услуги, навыки, опыт, контакты, язык, тема, пасхалка
    ├── office.js      — 3D-схема офиса, изображение с камер, рисунки камер
    ├── worldmap.js    — ASCII-карты мира (сгенерированы из Natural Earth)
    ├── geo.js         — внешний IP и место посетителя, проверка локального IP
    ├── info.js        — страница «Инфо»: карта и сведения о посетителе
    └── terminal.js    — интерактивный терминал (на странице «Инфо»)
```

## Терминал

`help`, `whereami` / `myip`, `whoami`, `neofetch`, `services`, `cam [1-4]`, `skills [id]`, `experience`, `certs`,
`contact`, `ls`, `cat <файл>`, `cd <раздел>`, `theme [dark|light]`, `lang [ru|uz|en]`, `sound [on|off]`, `matrix`,
`reboot` (на главную), `clear`, `history`, `date`, `echo`, `sudo …`, `exit`. Работают история (↑ ↓) и Tab.

## Языки, тема, звук, пасхалка

- **Языки** — `[ru|uz|en]` в шапке. Тексты интерфейса — в `js/i18n.js`, содержимое — в `js/data.js`.
- **Тема** — кнопка с луной/солнцем. Основная тема тёмная; выбор запоминается в браузере.
- **Звук** — кнопка с динамиком (по умолчанию выключен).
- **Пасхалка** — ↑↑↓↓←→←→ B A включает «режим матрицы» (то же — команда `matrix`).
- Если в системе включено «уменьшение движения», анимации не запускаются сами; их можно включить
  кнопкой `[ ▶ смотреть ]`.

## Что заменить своими данными (`js/data.js`)

- `contacts` — Telegram, телефон и почта сейчас заглушки;
- `experience` и `certs` — сейчас примеры;
- `profile.location` — город, откуда «идёт сигнал» на карте мира;
- тексты услуг и навыков — проверьте, что всё соответствует правде.
