# Портфолио — Хайруллаев Анваржон

Статичная страница в ASCII/терминальном стиле: открывается двойным кликом по `index.html`, сервер и сборка не нужны.

## Структура файлов

```
portfolio/
├── index.html         — каркас: интро, шапка, разделы, подвал
├── img/
│   └── logo.png       — логотип (интро, шапка, иконка вкладки)
├── css/
│   └── style.css      — ASCII-стиль, адаптивность, все анимации
├── js/
│   ├── data.js        — ВСЁ содержимое: профиль, контакты, навыки, проекты
│   ├── ascii-logo.js  — логотип как сетка яркости (сгенерирована из logo.png)
│   ├── fx.js          — ASCII-эффекты: расшифровка текста, вращающийся логотип, баннер из текста
│   ├── background.js  — анимированный ASCII-фон
│   ├── main.js        — отрисовка разделов, вкладки, фильтр, появление при прокрутке
│   └── intro.js       — ASCII-интро
└── README.md
```

## ASCII-фон

Движущиеся «линии уровня» из символов на весь экран, как на топографической карте. Вокруг курсора линии
становятся гуще и ярче, при прокрутке смещаются. Около 25 кадров в секунду; на скрытой вкладке фон останавливается.

## ASCII-интро

1. Загрузка «системы»: строки `[ OK ] ...` и полоса `[████████░░░░] 64%`.
2. ASCII-логотип собирается из символов от центра и делает оборот.
3. Печатается приветствие, имя появляется крупными буквами из блоков `█▓▒░`, затем «Я IT-администратор».
4. Всё рассыпается в символы, и сканирующая полоса «печатает» сайт сверху вниз.

Пропустить: `Esc`, `Enter`, пробел или клик. Если в системе включено «уменьшение движения», интро и фон
показываются без анимаций.

ASCII-логотип на главном экране делает оборот при наведении.

## Разделы страницы

1. **Обо мне** — имя, роль, текст о себе, ASCII-логотип в окне терминала.
2. **Навыки** — отдельная вкладка на каждую технологию, в таком порядке:
   1. HTML
   2. JavaScript
   3. CSS
   4. SQL
   5. Node.js
   6. Git
   7. … дальше добавляются новые
3. **Проекты** — карточки с тегами и фильтром по технологии.
4. **Контакты**.

## Как добавить технологию

Добавьте объект в массив `skills` в `js/data.js`. Его место в массиве задаёт порядок вкладок.

```js
{
  id: "linux",              // короткий уникальный id, его же указывают в projects[].tech
  title: "Linux",           // название на вкладке
  file: "setup.sh",         // имя файла над примером кода: $ cat setup.sh
  level: "Уверенный",       // Базовый · Средний · Уверенный · Продвинутый · Эксперт
  summary: "Одна строка о том, для чего использую.",
  points: ["Что умею 1", "Что умею 2"],
  snippet: "sudo systemctl status nginx", // необязательно
}
```

## Как добавить проект

Добавьте объект в массив `projects`. Проекты, которые там сейчас, — примеры, их нужно заменить своими.

```js
{
  title: "Название",
  description: "Что делает проект.",
  tech: ["html", "css", "js"],              // id из skills
  demo: "https://...",                      // необязательно
  code: "https://github.com/username/repo", // необязательно
}
```
