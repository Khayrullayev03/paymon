# Портфолио

Статичная страница: открывается двойным кликом по `index.html`, сервер и сборка не нужны.

## Структура файлов

```
portfolio/
├── index.html      — каркас страницы: шапка, разделы, подвал
├── css/
│   └── style.css   — стили, адаптивность, светлая и тёмная тема
├── js/
│   ├── data.js     — ВСЁ содержимое: профиль, контакты, навыки, проекты
│   └── main.js     — отрисовка разделов, вкладки навыков, фильтр проектов
└── README.md
```

## Разделы страницы

1. **Обо мне**: имя, роль, пара предложений о себе.
2. **Навыки**: отдельная вкладка на каждую технологию, в таком порядке:
   1. HTML
   2. JavaScript
   3. CSS
   4. SQL
   5. Node.js
   6. Git
   7. … дальше добавляются новые
3. **Проекты**: карточки с тегами технологий и фильтром по ним.
4. **Контакты**.

В каждой вкладке навыка есть уровень, краткое описание, список «Что умею», пример кода
и ссылка на проекты с этой технологией.

## Как добавить технологию

Добавьте объект в массив `skills` в `js/data.js`. Его место в массиве задаёт порядок вкладок.

```js
{
  id: "react",              // короткий уникальный id, его же указывают в projects[].tech
  title: "React",           // название на вкладке
  color: "#61dafb",         // цвет метки
  level: "Средний",         // необязательно
  summary: "Одна строка о том, для чего использую.",
  points: ["Что умею 1", "Что умею 2"],
  snippet: "const App = () => <h1>Привет</h1>;", // необязательно
}
```

## Как добавить проект

Добавьте объект в массив `projects`. Проекты, которые там сейчас, — примеры, их нужно заменить своими.

```js
{
  title: "Название",
  description: "Что делает проект.",
  tech: ["html", "css", "js"],              // id из skills
  demo: "https://...",                      // необязательно
  code: "https://github.com/username/repo", // необязательно
}
```
