# Портфолио — Хайруллаев Анваржон

Статичная страница в ASCII/терминальном стиле: открывается двойным кликом по `index.html`, сервер и сборка не нужны.

## Структура файлов

```
portfolio/
├── index.html         — каркас: интро, шапка, разделы, подвал
├── img/
│   └── logo.png       — логотип (шапка, иконка вкладки, исходник для ASCII)
├── css/
│   └── style.css      — ASCII-стиль, тёмная и светлая темы, адаптивность, анимации
├── js/
│   ├── i18n.js        — переводы интерфейса: ru, uz, en
│   ├── data.js        — ВСЁ содержимое: профиль, навыки, проекты, опыт, сертификаты, контакты
│   ├── ascii-logo.js  — логотип как сетка яркости (сгенерирована из logo.png)
│   ├── fx.js          — ASCII-эффекты: расшифровка текста, вращающийся логотип, баннер из текста
│   ├── sound.js       — звуки интерфейса (Web Audio, без файлов)
│   ├── background.js  — анимированный ASCII-фон и режим матрицы
│   ├── scenes.js      — живые ASCII-анимации для каждого навыка
│   ├── office.js      — 3D-схема офиса, изображение с камер, рисунки камер
│   ├── main.js        — отрисовка разделов, вкладки, фильтр, язык, тема, пасхалка
│   ├── terminal.js    — интерактивный терминал
│   └── intro.js       — ASCII-интро
└── README.md
```

## Разделы страницы

1. **Обо мне** — имя, роль, текст о себе, ASCII-логотип (поворачивается при наведении).
2. **01. Инфраструктура** — демо-схема офиса в 3D (ASCII):
   - стены, окно, дверь, рабочие места с мониторами, роутер с волнами Wi-Fi, коммутатор, серверная стойка;
   - кабели с бегущими пакетами: ■ — видео с камер на сервер, ● — данные;
   - сотрудники ходят по офису; 4 камеры с живыми конусами обзора на полу — когда человек попадает
     в конус, камера «замечает» его (над головой `!`, конус мигает);
   - **изображение с камеры**: вид выбранной камеры с панорамированием, REC, временем и рамкой
     `person 9x%` вокруг замеченного человека; камеру выбирают кнопкой или кликом по ней на схеме;
   - **рисунки камер**: настенная цилиндрическая с лучом обзора и купольная с ИК-подсветкой.
3. **02. Навыки** — две группы вкладок, порядок задаётся в `data.js`:
   - веб-разработка: HTML → JavaScript → CSS → SQL → Node.js → Git
   - администрирование: Linux → Windows Server → Сети → Серверы → Видеонаблюдение → Мониторинг

   В каждой вкладке: уровень `[████████░░]`, «что умею», **живая ASCII-анимация** и пример кода.
4. **03. Опыт** — места работы в виде системного журнала и сертификаты (`ls ~/certs`).
5. **04. Проекты** — карточки с тегами и фильтром по технологии.
6. **05. Терминал** — интерактивная командная строка.
7. **06. Контакты**.

## ASCII-анимации навыков (`js/scenes.js`)

| id | что происходит |
|---|---|
| html | страница собирается из блоков `<header>`, `<main>`, `<section>`… |
| js | курсор нажимает кнопку, в консоли срабатывает обработчик |
| css | три блока перестраиваются под flex, column, grid… |
| sql | запрос проходит по строкам таблицы и отбирает подходящие |
| node | запрос идёт клиент → сервер → база и обратно, пишется access.log |
| git | растёт граф коммитов, ветка сливается в main, ставится тег |
| linux | htop: живые нагрузки CPU, память, процессы |
| windows | в Active Directory создаётся пользователь, применяется GPO |
| network | пакеты бегут по сети интернет → роутер → коммутатор → устройства, ping |
| servers | стойка с мигающими индикаторами, загрузка виртуальных машин и контейнеров |
| cctv | камера поворачивается, замечает человека, тревога «MOTION DETECTED» |
| monitoring | живой график нагрузки, тревога в Telegram, ночной бэкап |

У каждой анимации есть кнопка `[ пауза ]` / `[ ▶ смотреть ]`. Если в системе включено «уменьшение движения»,
анимации не запускаются сами, но их можно включить этой кнопкой.

Сцена играет только у открытой вкладки и только когда её видно. Для нового навыка без своей сцены
показывается универсальная анимация «загрузки». Свою сцену можно добавить в `SCENES` по `id` навыка.

## Терминал

`help`, `whoami`, `neofetch`, `cam [1-4]` (открыть камеру офиса), `office`, `skills [id]`, `projects`, `experience`, `certs`, `contact`, `ls`, `cat <файл>`,
`cd <раздел>`, `theme [dark|light]`, `lang [ru|uz|en]`, `sound [on|off]`, `matrix`, `reboot` (заново показать интро),
`clear`, `history`, `date`, `echo`, `sudo …`, `exit`. Работают история (↑ ↓) и автодополнение (Tab).

## Языки, тема, звук, пасхалка

- **Языки** — `[ru|uz|en]` в шапке. Тексты интерфейса — в `js/i18n.js`, содержимое — в `js/data.js`.
- **Тема** — кнопка с луной/солнцем. Основная тема тёмная; выбор запоминается в браузере.
- **Звук** — кнопка с динамиком (по умолчанию выключен): щелчки клавиш в интро и терминале, сигналы.
- **Пасхалка** — ↑↑↓↓←→←→ B A включает «режим матрицы» (то же — команда `matrix`).

## ASCII-интро

1. Загрузка «системы»: строки `[ OK ] ...` и полоса `[████████░░░░] 64%`.
2. ASCII-логотип собирается из символов от центра и делает оборот.
3. Печатается приветствие, имя появляется крупными буквами из блоков `█▓▒░`, затем роль.
4. Всё рассыпается в символы, и сканирующая полоса «печатает» сайт сверху вниз.

Пропустить: `Esc`, `Enter`, пробел или клик. Если в системе включено «уменьшение движения», интро, фон и сцены
показываются без анимаций.

## Как добавить технологию

Добавьте объект в массив `skills` в `js/data.js`. Место в массиве и `group` задают, где будет вкладка.

```js
{
  id: "docker",                  // короткий уникальный id: вкладка, фильтр проектов, команда skills docker
  group: "admin",                // web — веб-разработка, admin — администрирование
  title: "Docker",               // строка или { ru, uz, en }
  file: "compose.yml",           // имя файла над примером кода: $ cat compose.yml
  level: "intermediate",         // basic · intermediate · confident · advanced · expert
  summary: { ru: "…", uz: "…", en: "…" },
  points: { ru: ["…", "…"], uz: ["…"], en: ["…"] },
  snippet: "docker compose up -d", // необязательно
}
```

## Как добавить проект, опыт, сертификат

В `js/data.js` есть массивы `projects`, `experience` и `certs`. Сейчас там **примеры** — замените их своими.
У проекта `tech` — это `id` навыков из списка выше; `demo` и `code` — необязательные ссылки.
