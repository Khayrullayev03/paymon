# Портфолио

Статичный сайт в ASCII/терминальном стиле под алой луной: открывается двойным кликом по `index.html`,
сервер и сборка не нужны.

## Как устроен сайт

- **Главная** — только логотип (ASCII, поворачивается при наведении или касании) на фоне алой луны.
- **Разделы — отдельные страницы**, открываются из меню в шапке с переходом «печати» (полоса из символов):

  | Адрес | Страница |
  |---|---|
  | `#office` | 01. Инфраструктура — 3D-схема офиса, изображение с камер, рисунки камер |
  | `#skills` | 02. Навыки — вкладки с живыми ASCII-анимациями |
  | `#experience` | 03. Опыт и сертификаты |
  | `#projects` | 04. Проекты с фильтром |
  | `#terminal` | 05. Терминал |
  | `#contact` | 06. Контакты |

  Работают кнопки «Назад/Вперёд» браузера и прямые ссылки (например, `index.html#skills`).
  На каждой странице есть ссылка `← меню` на главную.

## Фон: алая луна

Своя ASCII-луна (не арт из игры): объём с освещением сверху слева, светлый край, моря и кратеры,
медленное вращение, багровое свечение, плывущие облака и мерцающие звёзды. На главной луна крупная,
на остальных страницах — меньше и тусклее, в углу. Внизу экрана — движущиеся «линии уровня» из символов,
вокруг курсора они ярче. Около 25 кадров в секунду; на скрытой вкладке фон останавливается.

## 01. Инфраструктура

- Крупная 3D-схема офиса (до 24 px на символ, кнопка «во весь экран»): стены, окно, дверь, рабочие места,
  роутер с волнами Wi-Fi, видеорегистратор (NVR), коммутатор, серверная стойка, принтер, диван;
  кабели с бегущими пакетами (■ — видео, ● — данные), сотрудники ходят по офису.
- 4 камеры с живыми конусами обзора на полу. Когда человек попадает в конус, камера его «замечает».
- **Изображение с камеры**: вид выбранной камеры с поворотом, REC, временем и рамкой `person 9x%`.
  Камеру выбирают кнопкой, кликом по ней на схеме или командой `cam 1…4` в терминале.
- **Рисунки камер**: настенная цилиндрическая с лучом обзора и купольная с ИК-подсветкой.

## 02. Навыки и их анимации (`js/scenes.js`)

| id | что происходит |
|---|---|
| html | страница собирается из блоков `<header>`, `<main>`, `<section>`… |
| js | курсор нажимает кнопку, в консоли срабатывает обработчик |
| css | три блока перестраиваются под flex, column, grid… |
| sql | запрос проходит по строкам таблицы и отбирает подходящие |
| node | запрос идёт клиент → сервер → база и обратно, пишется access.log |
| git | растёт граф коммитов, ветка сливается в main, ставится тег |
| linux | htop: живые нагрузки CPU, память, процессы |
| windows | в Active Directory создаётся пользователь, применяется GPO |
| network | пакеты бегут по сети интернет → роутер → коммутатор → устройства, ping |
| servers | стойка с мигающими индикаторами, загрузка виртуальных машин и контейнеров |
| cctv | камера поворачивается, замечает человека, тревога «MOTION DETECTED» |
| monitoring | живой график нагрузки, тревога в Telegram, ночной бэкап |

У каждой анимации есть кнопка `[ пауза ]` / `[ ▶ смотреть ]`. Если в системе включено «уменьшение движения»,
анимации не запускаются сами, но их можно включить этой кнопкой.

## Терминал

`help`, `whoami`, `neofetch`, `cam [1-4]`, `office`, `skills [id]`, `projects`, `experience`, `certs`, `contact`,
`ls`, `cat <файл>`, `cd <раздел>`, `theme [dark|light]`, `lang [ru|uz|en]`, `sound [on|off]`, `matrix`,
`reboot` (на главную), `clear`, `history`, `date`, `echo`, `sudo …`, `exit`. Работают история (↑ ↓) и Tab.

## Языки, тема, звук, пасхалка

- **Языки** — `[ru|uz|en]` в шапке. Тексты интерфейса — в `js/i18n.js`, содержимое — в `js/data.js`.
- **Тема** — кнопка с луной/солнцем. Основная тема тёмная; выбор запоминается в браузере.
- **Звук** — кнопка с динамиком (по умолчанию выключен): щелчки клавиш в терминале, сигналы.
- **Пасхалка** — ↑↑↓↓←→←→ B A включает «режим матрицы» (то же — команда `matrix`).

## Как добавить технологию

Добавьте объект в массив `skills` в `js/data.js`. Место в массиве и `group` задают, где будет вкладка.

```js
{
  id: "docker",                  // короткий уникальный id: вкладка, фильтр проектов, команда skills docker
  group: "admin",                // web — веб-разработка, admin — администрирование
  title: "Docker",               // строка или { ru, uz, en }
  file: "compose.yml",           // имя файла над примером кода: $ cat compose.yml
  level: "intermediate",         // basic · intermediate · confident · advanced · expert
  summary: { ru: "…", uz: "…", en: "…" },
  points: { ru: ["…", "…"], uz: ["…"], en: ["…"] },
  snippet: "docker compose up -d", // необязательно
}
```

## Как добавить проект, опыт, сертификат

В `js/data.js` есть массивы `projects`, `experience` и `certs`. Сейчас там **примеры** — замените их своими.
У проекта `tech` — это `id` навыков из списка выше; `demo` и `code` — необязательные ссылки.
